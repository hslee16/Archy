### 1. `fix(graph): an import of a compiled extension module (.so/.pyd, usually with a .pyi stub) lands on the package __init__ and creates a false cycle`
- **Facts:** Python finds extension modules by their own suffixes (`importlib.machinery.EXTENSION_SUFFIXES`, https://docs.python.org/3/library/importlib.html#importlib.machinery.EXTENSION_SUFFIXES). Stub files are `.pyi` (PEP 484, https://peps.python.org/pep-0484/#stub-files).
- **Fixture `ext/`:**
  - `pkg/__init__.py`: `from .api import fast`
  - `pkg/api.py`: `from ._speedups import fast`
  - plus `pkg/_speedups.pyi` and `pkg/_speedups.cpython-312-darwin.so`
- **Observed:** `archy cycles &lt;ext&gt;` reports `pkg -&gt; pkg.api (line 1)` and `pkg.api -&gt; pkg (line 1)`, and `--strict` exits 1.
- **Real packages:**
  - grimp (copied from `.venv` into `research/real/`) shows one 7-module cycle. Every back-edge into `grimp` is a `from grimp import _rustgrimp as rust` line (caching:13, filesystem:6, graph:6, scanning:3).
  - PyYAML shows `yaml &lt;-&gt; yaml.cyaml` through `from yaml._yaml import CParser`.
- **Expected:** no cycle. A `.py` sibling would have given `pkg.api -&gt; pkg._speedups`.
- **Cause:** discovery only looks at `*.py` (`graph.py:579`). The unknown `pkg._speedups` then collapses to its longest internal prefix (`graph.py:738` into `_external_target`, `graph.py:960-970`). The `from grimp import _rustgrimp` form falls back to the bare base at `graph.py:663`.
- **Fix sketch:** during discovery, record the basenames of `*.so`/`*.pyd` (minus the ABI tag), `*.pyi` and `*.pyx` that have no `.py` twin. Add them as internal leaf modules with an empty `ParseResult`, so both resolution paths land on the leaf.
- **Acceptance:**
  - The fixture shows no cycle, and the edge is `pkg.api -&gt; pkg._speedups`. Also assert the `.py`-less extension really exists in the fixture.
  - The grimp copy shows no cycle.
  - Same answer through `archy_cycles` `model_dump()`.
  - Mutation: drop the extension-name collection, clear `__pycache__`, and the tests go red.
- **Label:** good second issue. It touches discovery plus one resolution path, and changes module counts, so it needs a bench note.
- **Closest ticket:** none. I grepped for extension, compiled, cython, .so and pyi. #387 (implicit `__init__` edges) is related but different.

### 2. `fix(conventions): read modules as bytes so a PEP 263 coding cookie is honoured, instead of silently dropping the module from "COMPLETE" answers`

### 4. `fix(parser): transcode non-UTF-8 sources before tree-sitter, so a Shift-JIS/Big5/GBK file loses no imports`
- **Facts:** PEP 263 (above). In Shift-JIS, `能` is 0x94 0x5C, and the 0x5C trailing byte is an ASCII backslash.
- **Fixture `sjis/`:**
  - `pkg/a.py`, Shift-JIS encoded: `# -*- coding: shift_jis -*-`, `LABEL = '機能'`, `from pkg import b`

- **Observed:**
  - `archy cycles` prints `# No cycles found`, and `--strict` exits 0.
  - The graph JSON has `parse_errors ['pkg.a']` and only the edge `('pkg.b','pkg.a')`.
- **Expected:** a 2-cycle.
- **Cause:** `parser.py:162-163`, where `parse_file` feeds raw bytes to a UTF-8 grammar.
- **Fix:** take the encoding from `tokenize.detect_encoding`. If it isn't utf-8, run `source.decode(enc).encode("utf-8")` before `parse_source`. Lines are preserved; I verified the transcoded parse is clean and puts the import on line 3.
- **Acceptance:**
  - The cycle is found and `parse_errors` is empty.
  - Assert first that the raw bytes contain `\x5c'`.
  - Mutation: remove the transcode, and the tests go red.
- **Label:** good first issue. **Weakness:** legacy CJK encodings are rare in 2026, though archy does print a parse-error warning for this case.
- **Closest ticket:** none.

### 6. `fix(complexity): an irrefutable case (case _ / case name) counts as a branch, so match scores one higher than the equivalent if/elif/else`

- **Cause:** `complexity.py:42` counts every `case_clause`. Also, `if_clause` (`complexity.py:49`, intended for comprehensions) counts match guards.
- **Fix sketch:** skip a `case_clause` whose only pattern is a bare `_` or a capture identifier. Decide the guard question explicitly.
- **Acceptance:** the three fixtures score equal. `tests/test_complexity.py:63-71` currently pins 4 and must change. Mutation: remove the skip, and the tests go red.

- **Label:** good first issue.
