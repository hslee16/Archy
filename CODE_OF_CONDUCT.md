# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html) as its code of conduct. The canonical text lives at that URL and is incorporated here by reference.

## Reporting

Report incidents to the maintainer listed in [`MAINTAINERS.md`](MAINTAINERS.md), or file a confidential issue. Reports are reviewed promptly; reporter identity is kept confidential to the extent possible.

## Enforcement

The maintainer (see [`MAINTAINERS.md`](MAINTAINERS.md)) is responsible for clarifying standards, investigating reports, and taking appropriate corrective action.
