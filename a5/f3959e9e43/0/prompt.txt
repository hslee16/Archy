The findings are about the edges, ranked below.

**1. Signals are not handled while the probe runs (medium, introduced here)**
`spawnSync` in `passesProbe` blocks the event loop, so the `onSignal` handler cannot run and `terminating` is never set in time.
- With a hanging probe, SIGTERM was ignored for 15.1s. The shim then exited **1** with the install hint instead of dying by the signal.
- With hanging `python3` and `python`, SIGTERM was sent at 0.7s. The second probe still started, and the shim exited 1 at 30.1s.
- If the parent escalates to SIGKILL, the probe child is orphaned (confirmed alive afterwards).
- The `if (terminating)` check in `start()` cannot catch a signal that arrives during a probe.
- Fix: probe with async `spawn`, assign the child to `active`, and check `terminating` before moving on.

**2. The probe timeout cannot stop a child that ignores SIGTERM (low)**
`spawnSync` sends SIGTERM by default. A stub with `trap "" TERM; exec sleep 35` left the shim still running at 50s despite `timeout: 15000`. Add `killSignal: "SIGKILL"`, or cover it in the async rewrite.
