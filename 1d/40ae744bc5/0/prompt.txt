All are in `/Users/hosanglee/archy/src/archy/conventions_exports.py`. My 115 runnable small modules gave 58 `complete=true` mismatches.

**1. `__all__` escaping by reference is not detected (top severity).** `_writes_all` only sees Store/Del names, subscript writes and direct `__all__.&lt;mutator&gt;()` calls. Each of these reports `{A}` as complete, while runtime is `{A, B}` (or `{B}` for the slice write):

- Alias: `a = __all__; a.append("B")`, `a += ["B"]` or `x[:] = ["B"]`.
- Chained assignment: `__all__ = a = ["A"]` or `a = __all__ = ["A"]`, then `a.append("B")`. The statement counts as handled and the alias is missed.
- Other escapes: `add = __all__.append`, `getattr(__all__, "append")`, `map(__all__.append, ...)`, `list.append(__all__, "B")`, `heapq.heappush`, `bisect.insort`, `(x := __all__).append`, `(__all__ or []).append`, `for l in (__all__,)`, `b = [__all__]; b[0].append`.
